# 松鼠助手 🐿️ · 演示版

账单不离开浏览器的智能账单分析网站。上传微信 / 支付宝导出的账单 CSV，在本地完成解析、
转账对冲、纠错确认，输出收支全貌（桑基图）、月度环比和可分享的动物人格报告卡片。

**零后端**：没有服务器、没有账号、没有数据库。原始账单只在浏览器内存中解析，
分析结果仅保存在 localStorage，可导出 JSON 存档随身携带。

## 功能

- 📥 双平台 CSV 导入（自动识别微信 / 支付宝格式，GBK / UTF-8 自动解码）
- 🔁 转账对冲引擎：跨平台同额配对（支付宝→微信零钱）、花呗 / 信用卡还款识别，
  内部转账不计收支；拿不准的进纠错队列让用户一键确认
- 🏷️ 自动分类（关键词规则 + 支付宝交易分类映射），用户手改永久优先
- 📊 报表：收支总览、环比、分类环形图、资金流向桑基图、Top 商户、月度趋势
- 🐾 动物人格：由结余率 / 消费集中度 / 夜间占比 / 波动率 / 单笔中位数 5 维度推导 8 种动物，
  金额可见 / 隐藏双版本分享卡片，一键导出 PNG
- 💾 存档导出 / 导入（换设备不断环比）

## 开发

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 生产构建（输出 dist/）
npm run preview    # 预览生产构建
npx vitest run     # 核心引擎单元测试
```

## 部署（静态托管即可）

`npm run build` 后把 `dist/` 目录部署到任意静态托管：
Cloudflare Pages / Vercel / GitHub Pages / 任意 Nginx 静态目录。
无需 Node 服务端，无需数据库。

## 演示版不做（正式版路线）

邮件订阅与月末提醒、截图识别、银行 CSV、跨用户匿名基准、账号体系。

## 目录结构

```
src/
  core/          纯函数引擎：解析 / 清洗 / 分类 / 对冲 / 人格 / 存档（含单测）
  store/         zustand + localStorage 持久化
  pages/         导入 / 核对 / 报表 / 人格 / 隐私
  components/    通用 UI 与 ECharts 封装
  demo/          内置演示账单（一键体验）
tests/           单元测试
```
