# 松鼠助手 🐿️ · 演示版

账单不离开浏览器的智能账单分析网站。选择你在用的金融APP → 导出账单拖进来 →
转账自动对冲、消费洞察、动物人格报告，三分钟看清收支全貌。

**零后端**：没有服务器、没有账号、没有数据库。原始账单只在浏览器内存中解析，
分析结果仅保存在 localStorage，可导出 JSON 存档随身携带。

## 功能

- 🧭 **金融APP选择向导**：微信/支付宝/云闪付/京东金融/招商/中信/工商/建设/农业银行/美团，
  点击即查看各APP的账单导出路径；未支持平台诚实标注"即将支持"
- 📥 **双格式导入**：CSV 与 Excel(xlsx)（微信新版导出格式）均可，GBK / UTF-8 自动解码，
  按表头指纹自动识别平台
- 🔁 **转账对冲引擎**：跨平台同额配对（支付宝→微信零钱）、花呗/信用卡还款识别，
  内部转账不计收支；拿不准的进纠错队列让用户一键确认
- 🏷️ 自动分类（关键词规则 + 支付宝交易分类映射），用户手改永久优先
- 💡 **洞察引擎**：结余率评价、环比变化、类目结构、刚性支出、深夜消费、
  花钱风格（高频小额/低频大额）、周末规律、最大单笔等数据驱动洞察
- 📊 **报表**：收支总览与环比、分类环形图、资金流向桑基图、周内规律、单笔金额分布、
  分类环比表、Top 商户、月度趋势
- 🐾 **动物人格**：5 维度推导 8 种动物（松鼠/仓鼠/蝴蝶/猫头鹰/熊猫/蜜蜂/刺猬/候鸟），
  金额可见/隐藏双版本分享卡片，一键导出 PNG
- 💾 存档导出/导入（换设备不断环比）

## 开发

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 生产构建（输出 dist/）
npm run preview    # 预览生产构建
npx vitest run     # 核心引擎单元测试
```

## 部署（静态托管即可）

`npm run build` 后把 `dist/` 部署到任意静态托管：
Cloudflare Pages / Vercel / GitHub Pages / 任意 Nginx 静态目录。
无需 Node 服务端，无需数据库。

## 演示版不做（正式版路线）

邮件订阅与月末提醒、截图识别、银行账单解析、跨用户匿名基准、账号体系。

## 目录结构

```
src/
  core/          纯函数引擎：解析/清洗/分类/对冲/洞察/人格/存档（含单测）
  store/         zustand + localStorage 持久化
  pages/         导入向导/核对/报表/人格/隐私
  components/    通用 UI 与 ECharts 封装
  apps.ts        金融APP目录（含各APP取账单路径）
  demo/          内置演示账单（一键体验）
tests/           单元测试
```
